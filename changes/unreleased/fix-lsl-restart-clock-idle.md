### Bugfixes

- **LSL: a restarted sender was sometimes never found again.** A device's streams share one source id (its EEG and its accelerometer), and the search for the restarted stream took the first answer — the accelerometer's as often as not — so the session sat beside a stream that was back until the idle timeout ended it. The stream is now looked for by source id and name. A restart is noted (marker `source restarted`, counted in the trace) whichever way the connection came back, and the new sender is asked for what it sent in the meantime.
- **LSL: time stamps ran ahead on a slow link.** With 400 ms between a sender and this machine, a recording's time stamps drifted up to 92 ms ahead and stayed off for a minute after the link was normal again (rlsl ≤ 0.1.1 reads the answer to a time query against the query sent last, not the one it answers). The sender's clock is now measured by skill itself, every answer matched to its own query, slow exchanges not believed, and the offset moved no faster than clocks drift.
- **LSL: the idle timeout setting had no effect.** The session runner ended every silent session after a fixed 30 s. An LSL session is now ended after what the LSL tab says (and never, when that is off); the default is 2 minutes instead of 15 s, so that a sender that is restarted or cut off for a while is back in the same session.
