### Build

- **`npm run release -- --stable`** ships the bare version (0.1.2, not 0.1.2-rc.2) instead of promoting an RC build that keeps its `-rc.N` version. Run 1 merges every RC's notes into one fragment, bumps to the bare version, pushes and tags so CI builds a normal release. Run 2, once the builds pass, rebase-merges the PR. It is a fresh build of the same commit, not the exact bytes tested as the RC.
- **Releases are checked against what is published, not what the clone last saw**: `npm run release -- --rc` now fetches first and refuses, with the fix, to cut an RC on a version that already shipped, to reuse an existing tag, to branch from a local `main` behind `origin/main`, or to use a release branch whose upstream is not `origin/<branch>`. From `main` with a shipped version it starts the next patch by itself, and it passes the chosen version to `bump` explicitly.
- **`npm run bump` can be interrupted safely**: Ctrl-C reverts the bump and exits 130 (it used to leave a half-applied bump), and a failed bump now restores only the files it changed instead of running `git checkout -- .`, so your own uncommitted edits are no longer thrown away.
- **`npm run tag` explains itself and is safe to repeat**: it reports a tag that exists on another commit or on a remote instead of exiting silently, checks every remote before changing anything, never moves a published tag, and pushes a tag that already sits on HEAD.
- **`npm run check:test-targets`** fails if a test file in a crate with `autotests = false` is not registered in `tests/it.rs` or as a `[[test]]`, which would otherwise be skipped silently. It also runs in the bump preflight.
- **`npm run check:cross`** type-checks the Windows daemon and app through cargo-xwin, so a break that only shows off macOS (like the `sysinfo` 0.40 change in `skill-gpu`) is found before tagging. `release --rc/--stable --cross-check` runs it first.
- **`npm run clean:rust:debug`** wipes `target/debug` and `tmp` and reports the space reclaimed (`--dry-run`, `--rebuild`), since stale build generations otherwise grow it to about 17 GB.
